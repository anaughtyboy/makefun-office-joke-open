`main.ts` validates the line (1–200 characters, single line, no leading or trailing whitespace, no control characters) and writes exactly those bytes to `MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), with no trailing newline, then reads the file back and confirms an exact byte match.
